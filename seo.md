Act as a senior SEO engineer and full-stack web developer. Audit my website/app and make it fully SEO-friendly according to current Google best practices (technical SEO, on-page SEO, performance SEO, accessibility, and structured data).

Your goal is to improve search engine visibility, indexing, rankings, and click-through rates without breaking functionality.

## Tasks

### Technical SEO

* Ensure every page has a unique and optimized `<title>` tag.
* Add meaningful meta descriptions for every page.
* Implement canonical URLs.
* Add robots meta tags where appropriate.
* Generate a valid `robots.txt`.
* Generate a valid `sitemap.xml`.
* Ensure clean, descriptive, SEO-friendly URLs.
* Fix duplicate content issues.
* Improve crawlability and indexability.

### On-page SEO

* Ensure a proper heading hierarchy (one H1 per page, logical H2/H3 structure).
* Optimize page content for search intent.
* Improve semantic HTML.
* Add descriptive image alt text.
* Optimize internal linking between relevant pages.
* Identify missing content that should be added for SEO.

### Structured data

* Implement JSON-LD schema markup where appropriate, including:

  * Organization
  * Website
  * Breadcrumbs
  * Article/Blog
  * Product
  * FAQ
  * Local Business
* Validate schema structure.

### Performance SEO

* Improve Core Web Vitals.
* Optimize Largest Contentful Paint (LCP).
* Reduce JavaScript bundle size.
* Eliminate render-blocking resources.
* Enable lazy loading for images and media.
* Optimize fonts.
* Compress and modernize images (WebP/AVIF).
* Improve caching strategy.

### Mobile SEO

* Ensure full mobile responsiveness.
* Verify viewport configuration.
* Improve touch targets and mobile usability.

### Accessibility

* Improve semantic structure.
* Add missing ARIA labels where necessary.
* Ensure keyboard accessibility.
* Improve color contrast where relevant.
* Use accessible form labels.

### React/Vite or SPA considerations

* Ensure pages are indexable by search engines.
* Add dynamic metadata management.
* Recommend SSR, SSG, or prerendering if beneficial.
* Prevent blank-page indexing issues common in SPAs.

### Deliverables

For every issue you find:

1. Explain why it hurts SEO.
2. Show the exact code changes required.
3. Provide the updated code.
4. Explain the expected SEO impact.

At the end, provide:

* An SEO score out of 100.
* A prioritized action plan (high, medium, low priority).
* A checklist of completed SEO improvements.
* Any additional recommendations for long-term SEO growth.

Do not give generic SEO advice. Make concrete code-level improvements and refactor the project where necessary to achieve production-grade SEO.
